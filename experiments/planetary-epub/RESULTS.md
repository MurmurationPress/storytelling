# Playback defect investigation — playback-v2

**Ted's v1 defect is real user evidence, but its exact cause is not established.** He reports that Begin flashes and immediately reveals complete YAML in Thorium Desktop 3.5.1 on Linux with default installed settings. This qualifies the earlier success claim. The [original report](evidence/RESULTS-v1.md), original EPUB, screenshots and browser results are retained as historical evidence, not proof that Ted's environment worked.

The original EPUB did **not** reproduce the flash-and-immediate-reveal symptom in this investigation's fresh default-profile native test. The revised build also visibly progresses over several seconds with pointer, Enter and Space. Playback-v2 removes two demonstrated vulnerabilities and explains static reduced-motion output; it is a candidate correction for Ted to retest, not a verified diagnosis of his machine. No settings change is requested. Automatic arrival activation remains outside scope.

## Native environment and method

Official Thorium Desktop **3.5.1**, Linux amd64 release DEB, unmodified, extracted into a temporary directory; Zorin OS **18.1**, x86_64, GNOME Wayland desktop. Separate empty `--user-data-dir` profiles were used for original, original diagnostics, playback-v2 and playback-v2 diagnostics; appearance/settings were left at defaults. `--ozone-platform=x11` enabled X11 input/window capture, as in the first investigation. No reader security setting, OS motion preference or reader code was changed. A remote-debugging launch was refused by the reader's packaged CLI; it was abandoned, without bypass, in favour of publication-local diagnostics. Native Wayland rendering without that X11 platform flag is not independently verified.

Real pointer and keyboard events were sent to the reader's native window; ImageMagick captured the window at successive times. These are not screenshots of unpacked XHTML in a browser. Diagnostic variants add local tracing and a selectable diagnostic text block; the ordinary v2 EPUB contains no diagnostic script/panel. Publication identifiers, library titles, filenames and the state-page build label distinguish old, new and diagnostic imports.

## Correction and retained behaviour

1. Complete YAML now uses **opacity**, rather than text colour, to reserve a stable layout invisibly during performance. This survives colour overrides while retaining full authored text for nonvisual access. The visual partial overlay remains aria-hidden; no-script markup still presents complete text.
2. Document-hidden pauses the existing prefix instead of calling showAll. Visible resumes that already explicitly started performance. Actual pagehide still reveals full text, and a fresh state document starts complete with optional Replay. A reader retaining documents without pagehide may resume rather than return complete; no universal reader-location contract is claimed.
3. Duplicate Begin activation cannot restart a running timer. Replay works after completion or immediate reveal. Controls retain fixed widths and reader navigation keys remain untouched.
4. Reduced motion has an understandable static initial state; enabling it during output stops and explains the static display, without an unexplained flash. Turning reduced motion off makes optional Replay available. No setting change is needed to read the full text.

No manuscript content, YAML whitespace, paragraph order, image bytes or narrative image placement changed. Prose remains reflowable; state/image retain the two fixed surfaces. No automatic start was added.

Local success does not resolve Ted's contradictory result until he retests the distinct new import.

See `browser-results.json` and `original-browser-mechanisms.json`. These are not native-reader lifecycle or accessibility claims.
- **Packages:** both v2 EPUBs pass EPUBCheck **5.3.0** with **zero errors and warnings**. Source-preservation verification passes separately for both, including exact paragraphs/YAML, ordered spine, original SVG byte identity and all local references. No network resources are required. Rebuilds are byte reproducible.
- **Unverified:** Ted's exact failure path; native OS reduced-motion/no-script modes (settings were left alone); native Wayland-only path; touch, screen reader, iPad and other readers. No second standard EPUB reader is installed. Chromium is not counted as a secondary EPUB reader.
