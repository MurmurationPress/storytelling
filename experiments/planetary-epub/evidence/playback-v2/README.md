# Playback-v2 evidence

See [current results](../../RESULTS.md) for interpretation and limitations. All PNGs here are native Thorium 3.5.1 Linux reader-window captures, obtained through X11 pointer/keyboard input and ImageMagick `import -window`. They are not browser screenshots. The original report and original evidence remain separately preserved.

`normal-pointer`, `normal-keyboard` (Enter), and `normal-keyboard-space` each contain five temporally separated frames of the ordinary v2 EPUB, including completion. Per-sequence `frames.json` gives the activation and actual elapsed capture times. Visually compare successive prefixes and the blank reserved area below them. Keyboard runs replay the output after the preceding run has completed. The primary playback logic was unchanged during these runs and final packaging; later diagnostic-only log styling does not occur in the primary document.

`original` contains the unchanged original EPUB pointer sequence. `original-diagnostics.json` is a separate original-logic run with temporary reason logging before Begin/showAll and 250 ms computed-style/count samples. Instrumentation did not change the original reveal or lifecycle decisions. It shows normal progression, not Ted's reported failure.

`diagnostic-pointer`, `diagnostic-keyboard` and `v2-diagnostics.json` record early v2 diagnostic runs (then using a textarea log). The final diagnostic changes only log presentation/export to a real text node; playback code is identical. `v2-lifecycle-diagnostics.json` is exported from the **final diagnostic artifact** with Ctrl+A / Ctrl+C, extracting the JSON suffix from the copied page. Its natural completion takes 5,331 ms. It includes departure during typing, return before the nominal original performance would finish, later return, and immediate reveal. `final-diagnostic-completion.png`, `early-departure.png`, `quick-return.png`, `later-return.png` and `immediate-reveal.png` accompany that final run. Complete output on return is expected; it is not evidence of a flash on Begin.

Times in `ms` are relative to each document instance; compare `instance` before subtracting them. `at` gives wall-clock timestamps. Samples store visual partial `chars`, reduced-motion matches, document visibility, performing state and computed styles for both text layers. Show-all clears the overlay, so its `chars` is zero while the complete text becomes visible. Visibility was still reported as visible at the observed native departures; pagehide is recorded separately.

`original-browser-mechanisms.json` demonstrates two synthetic browser failure paths on v1, not the cause of Ted's native result. `browser-results.json` records final browser regression coverage; browser results are not native-reader results. Both EPUBCheck reports are for final v2 artifacts. `artifacts.json` records SHA-256 values and the byte-identical rebuild check.

The final diagnostic uses the reader's whole-page Select All / Copy because native reader selection can bypass textarea content. Paste the whole copied state page and JSON if reporting a failure; there is no external service, clipboard permission workaround or reader modification. The ordinary EPUB has no log panel.
