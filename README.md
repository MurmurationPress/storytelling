# Murmuration Storytelling

A working notebook for a mixed-media storytelling platform, explored through human/AI collaboration and the PRIME Trilogy.

The vault preserves ideas and evidence. The accepted EPUB experiments now support one limited milestone for reusable PRIME and authored chat in a managed reader; broader platform ideas remain exploratory.

## Open the vault

Clone or download this repository, then use **Open folder as vault** in Obsidian and select the `vault` folder. Start with [Home](vault/Home.md). The vault is versioned inside the repository; it is not a separately maintained copy.

Only built-in Obsidian features are required. Notes are ordinary Markdown and remain usable without Obsidian. The repository includes focused EPUB/reader experiments; they are not production publishing infrastructure.

## Working arrangement

- `vault/` — ideas, decisions, questions and prototype studies.
- `experiments/` — the reviewed EPUB extract, managed reader integration and evidence.
- Obsidian is the current workshop. Its suitability as the long-term authoring platform is an open question.
- The repository is [MurmurationPress/storytelling](https://github.com/MurmurationPress/storytelling). **Murmuration Storytelling** is a working project title, not an agreed product name.
