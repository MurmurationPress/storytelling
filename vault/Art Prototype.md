# Art Prototype

## Relationship to the first capability test

[[Planetary Model EPUB Test]] is now the immediate first experiment: prose, typed PRIME state YAML, an existing image and a return to prose in an EPUB reader. Art remains the broader mixed-media chapter study once that reading transition is understood.

## Selected source

Ted identified **Art**, a chapter from **CONSTRAINT**, as a good starting point. CONSTRAINT's introduction of Companions also makes it a promising source for exploring the medium.

Earlier discussion considered EMERGENCE. Art was selected as the broader chapter study; the later Planetary Model choice narrows the first technical test. Neither requires adapting the full book.

## Work to do before implementation

1. Locate and read the current authoritative Art chapter in the PRIME manuscript repository.
2. Identify its actual prose, conversations, artwork and transitions.
3. Map the chapter into a provisional storyboard, preserving manuscript wording and identifying any proposed adaptations separately.
4. Choose a small complete sequence that demonstrates a useful change of medium.
5. Agree what we want to learn from a reader trying it.

No chapter text or artwork has been copied into this repository. No source path or source revision is pinned yet. The old attached ZIP should not automatically be treated as the current publication source.

## Candidate experiments

- Authored chat playback with pauses and typing indicators.
- Images revealed at the appropriate narrative moment.
- Page turning and return from supplementary material.
- An interactive Canvas, if the chosen passage supports it and we can define what the interaction means.

These are candidates rather than claims about the chapter's contents. Avoid forcing all five delivery forms into a single demonstration.

## Separate experiment

[[PRIME and JANUS]] dialogue could be a second, small study of contrasting output styles. It need not delay Art.

## Possible first-version boundaries

A browser experience usable on Ted's iPad and Linux machines was proposed. Payment, accounts, full-book conversion and a general-purpose publishing system need not be part of the first experiment. Those boundaries remain proposals until we select the experiment.
