# Synthetic export fixture

Three scenes in two parts, ordered only by `story-teller.project.json`.
All prose, dialogue and notes here are fictional. Both JANUS display labels
select distinct supporting files. Missing definition/image and a blocked
remote image are intentional diagnostics, not required network resources.

`assets/harbour-lamp.webp` is an original four-frame, lossless 96×64 animation:
an amber circle of radii 8, 13, 20, 13 on a dark background, 180ms per frame.
It was drawn locally for this fixture, without third-party footage.
`harbour-portrait.png` is the repository's existing original fictional test asset.
Image frame playback is deliberately independent of StoryPlayer's clock.
This README is not publication content and is not exported.
