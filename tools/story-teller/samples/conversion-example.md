title: Fictional chat conversion example
---

Ari rested the radio on the table.

```chat
# Harbour link
> Ari

{{Ari|Is the lamp still lit?|}}

{{Bo|First line.
Second line, with a colon: keep this together.

@pause 500ms is part of this message, not a setting.|}}
```

The receiver clicked twice.

```chat
{{Bo|A literal \| mark.|}}
{{|And one more message.|}}
```

This last block needs review because its subtext carries information.

```chat
{{Bo|Wait.|quietly}}
```

Ari said, “I'll wait.” Ordinary spoken dialogue is not a chat container.
