# Synthetic formatted-media review

Open this folder in VS Code with Story Teller 0.17.0 installed, then select
**Media inside components** from Part–Scene Outline. All text and assets are
synthetic. No source book or external connection is needed.

1. Play the first beat: JANUS report, internal analysis and annotation share one
   beat, each with its own title/timestamp. Pause, resume, change speed, Reveal,
   Replay and Restart. Annotation text types; each image/diagram enters whole.
2. Inspect table and diagram horizontal scrolling at a narrow width. Change
   theme. Media must remain inside the component and inspection must suspend
   Follow story. Repeated images must remain loaded.
3. Next during preparation/replay: no previous component should return. Beat two
   intentionally contains a missing image and invalid Mermaid. Both show readable
   fallbacks; the conclusion still appears and completion works.
4. Beat three exercises legacy JANUS beat-title compatibility. Beat four is YAML:
   all media-like syntax stays literal and loads nothing. Previous reveals a
   complete, silent beat. Reduced motion shows complete prepared content.

Export with **Story Teller: Export Web Reader** into a new directory and serve it
over HTTP for the same checks independently of the source workspace. The fixture
includes PNG/JPEG/WebP, spaces/Unicode filenames, captions, list/table/inline
images, multiple styles and nested fences. The linked Media note describes the synthetic illustration only; its preview and
full text contain no later disclosures, and it has no onward links.
